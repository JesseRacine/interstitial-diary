# Interstitial Diary

A quick, searchable interstitial journal: short timestamped notes between tasks, with `#tags`, saved as
plain Markdown files. Runs as an installable web app on Windows and Android (native apps planned).

- [DESIGN.md](DESIGN.md): how it works
- [PROGRESS.md](PROGRESS.md): what's done and what's next
- [CLAUDE.md](CLAUDE.md): working notes for AI-assisted development

```bash
npm install
npm run dev     # http://localhost:5173
npm test
npm run build
```
